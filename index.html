Font Mapper

Print a template, fill it in by hand, scan it back in, download your font.

Print at 100% scale ("Actual size" / no "fit to page"). Fill each box with dark pen or marker, staying inside the light gray guide box — the gray lines and baseline are printed light on purpose so they won't be picked up as ink when you scan it back in. Do not draw over the 4 black corner squares or the QR code — that code records exactly which letters are on that page, so pages can be scanned back in in any order. Ligature boxes are wider — draw the letters connected, the way you'd write them together, and typing those letters in sequence will use your connected version instead of the separate letters.

Step 1 — Upload your filled-in scan(s)

A flat, well-lit photo or scan works. JPG/PNG. If your template printed as more than one page, select all of them at once — most file pickers let you ctrl/cmd-click or shift-click to multi-select. Order doesn't matter: each page's QR code records which letters are on it, so pages sort themselves out automatically.

Spacing & kerning

Each letter's width was auto-scanned from its own ink, not a fixed box, so narrow letters like "i" don't carry the same width as "m". Drag the blue line to change the gap before a letter, and the orange line to change how much room it takes up before the next one starts — drag right on the letter itself, not in a separate field.
